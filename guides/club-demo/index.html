How club bookings work with Totality

Two short walkthroughs. Turn the sound on for the music, or watch it muted. Each one explains what happens before it shows it.

1Without the club system API

Members tap Book in the club app, pick a time and they're done. At the end of each billing period the club downloads one charges file.

2With the club system API

Members book on the club app's own screens, court bookings come through too, and charges go straight onto member accounts.
