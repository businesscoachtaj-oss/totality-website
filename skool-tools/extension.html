Free Chrome extension

Promo tracker for Chrome

Open any Skool group you track and a small note in the corner tells you when you last posted there, whether you can promote today, and if you've already posted on that exact page.

What it does

Shows a note on Skool group pages with your last promo date and when you can post again.
Warns you when you've already posted on the page you're looking at.
One click opens the full tracker to log a post, with the page link filled in.
Everything stays in your own browser. It only needs permission to store your tracker data.

What it never does

It never posts, comments, likes or messages for you, and it doesn't read your Skool pages or send anything anywhere. You stay in control of every post, which is how Skool wants promotion done.

Install it (2 minutes)

It isn't in the Chrome Web Store yet, so for now you add it yourself:

  1. Download the extension (zip)
  2. Unzip it. You'll get a folder with a file called manifest.json inside.
  3. In Chrome, go to chrome://extensions (type it into the address bar).
  4. Turn on Developer mode at the top right.
  5. Click Load unpacked and choose the unzipped folder.
  6. Pin it from the jigsaw icon. Click it any time to open your tracker.

Already using the web tracker? Download a backup from its Backup tab and load it in the extension's tracker, so both have the same groups.
