Totality Exercise API

The exercise library inside Totality, for your own app. 751 exercises written in plain English to one coaching standard, with setup steps, coaching cues, common mistakes, rep ranges, muscles, equipment and easier and harder versions, plus the videos we own.

Private beta. Last updated 20 November 2026

The API only serves our own animated videos. Exercises without one yet come back with has_video: false, and new videos are added every week.

How it works

REST and JSON. Send your key in the Authorization header. Every response says how many calls you have used this month.

# One exercise
curl https://spqazfyxxhzizbtmxklr.supabase.co/functions/v1/exercise-api/v1/exercises/zercher-squat \
  -H "Authorization: Bearer tx_live_your_key"
{
  "data": {
    "id": "zercher-squat",
    "name": "Zercher Squat",
    "description": "A squat with the barbell held in the crook of your elbows, behind your forearms. It keeps the torso upright and works the quads and upper back.",
    "difficulty": "advanced",
    "equipment": ["Barbell", "Rack"],
    "muscles": { "primary": ["Quads", "Glutes"], "secondary": ["Upper Back", "Abs", "Biceps"] },
    "setup_steps": ["Set the bar in a rack at about waist height.", "Hook it in the crook of your elbows and clasp your hands.", "Stand up and set your feet about shoulder width."],
    "coaching_cues": ["Keep the bar tight to your body.", "Sit down between your heels.", "Keep your chest up.", "Drive up through the whole foot."],
    "common_mistakes": ["Rounding the upper back.", "Letting the bar drift forward.", "Short range.", "Going too heavy for the elbows."],
    "rep_ranges": "Strength: 5-8",
    "easier": ["goblet-squat"],
    "harder": ["front-squat"],
    "has_video": true,
    "video": { "type": "animation", "mp4": "https://.../anim-zercher-squat-v4.mp4?token=...", "expires_in": 3600 }
  }
}

Endpoints

GET/v1/exercisesList. Filter with muscle, equipment, difficulty, goal and q (name search). limit up to 100, offset for paging. GET/v1/exercises/{id}One exercise by its id, for example zercher-squat. GET/v1/exercises/{id}/alternativesUp to 10 swaps that train the same main muscle group, nearest difficulty first. GET/v1/musclesEvery value the muscle filter accepts. GET/v1/equipmentEvery value the equipment filter accepts. GET/v1/changes?since=2026-11-01Exercises added or changed since a date. Studio and Licence plans. GET/v1/usageYour plan, and calls used this month.

Base URL: https://spqazfyxxhzizbtmxklr.supabase.co/functions/v1/exercise-api. Errors come back as {"error": {"code", "message"}} with a 4xx status. Video links last 1 hour, so ask for the exercise again rather than saving the link.

OpenAPI spec for Postman, Insomnia or code generators: totality360.com.au/api-openapi.json

Questions

Who writes the content?

Every exercise follows one written standard: plain English, the same fields on every exercise, and links to real easier and harder versions in the library. It is the same library Totality's trainers and clients use every day.

Can I store the data?

You can cache exercise text for up to 30 days. Videos are streamed through short-lived links and are not for downloading. The Licence plan is for teams that need to host everything themselves.

Is it medical advice?

No. It is general exercise information. Apps that use it should tell people to check with a doctor or qualified professional before starting a new programme.
